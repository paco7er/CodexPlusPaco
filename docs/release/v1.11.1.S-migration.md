## 请求体上限

- `helperMaxRequestBodyMib` 默认 128，读取、保存和部分更新均约束为 32~512 MiB。
- 旧设置缺少该字段时自动使用 128，前端保存其他设置时保留该值。
- `CODEX_PLUS_MAX_HTTP_BODY_BYTES` 以字节为单位，优先于设置；低于 32 MiB 或非法值忽略，高于 512 MiB 则夹取。
- 管理器启动、Codex 启动流程和管理器保存设置时应用上限；手改设置文件后需重启管理器或再次启动 Codex。
- 编码请求体缓冲上限为解码上限的两倍，最高 512 MiB；解压后的大小仍受解码上限约束。
- 413 提示指向实际配置字段及环境变量，不引用已删除页面。

## 保留边界

不恢复常驻代理、HTTP 状态码重试、独立增强页、Claude、语音、Fast、皮肤、
多开、请求日志、拓展管理或聚合模型分组。插件市场开关仍位于概览。
现有每模型窗口、自动压缩、供应商版本冲突保护及第三方拓展 API 契约保持不变。
