## 冲突处理

- 默认行为不变：实时地址无法归属时停止，不自动导入或覆盖。
- 仅用户主动切换且遇到地址冲突时弹窗，可取消、导入为新供应商，或备份后继续切换。
- 导入复用现有 `AdoptLiveIdentity`：地址与认证取自同一组实时文件，旧命名 Key 和自定义认证头不混入，新供应商生成独立 ID，原供应商快照不变。
- 弹窗关联 `config.toml` 与 `auth.json` 的内容摘要；确认期间任一文件变化就停止，不能使用旧选择覆盖新内容。
- 新增的冲突备份写入 Codex++ 状态目录的 `backups/codex-plus-live-<uuid>/`，便携版对应 `data/state/backups/`，备份失败不切换。
- 沿用原有配置应用与回滚机制；原配置写入流程已有的 Codex home 备份行为未在本次修改。
- 弹窗使用现有组件与样式，默认聚焦取消，支持 Escape 与焦点循环，不增加常驻轮询。

## 保留边界

不迁移 Key 首尾预览、WSL 聚合目录修复、注入式会话删除修复、额度解锁及 Claude 修复。
不恢复已移除页面、常驻代理或启动自动导入，不修改版本号、tag、打包脚本及正式用户配置。
